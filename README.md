# Notebook Didático de Python e Data Science

Este repositório contém um notebook interativo desenvolvido no ambiente **Google Colab**, projetado como um guia introdutório e prático sobre a linguagem **Python aplicada à Ciência de Dados**.  
O material integra fundamentos teóricos, sintaxe básica e exercícios práticos, com o objetivo de consolidar o aprendizado das principais estruturas de programação.

## 🎯 Objetivo do Notebook

O foco deste material é fornecer uma **base sólida em Python**, abordando desde a manipulação de dados em memória até a implementação de lógicas de decisão e repetição.  
O notebook funciona como um **recurso acadêmico introdutório** para estudantes e iniciantes que desejam compreender o funcionamento da linguagem em ambientes de computação em nuvem baseados em *notebooks*.

## 📚 Tópicos Abordados

O conteúdo está organizado de forma modular, favorecendo o estudo progressivo e a consulta estruturada.

### 1. Conceitos Iniciais e Ambiente

- **Google Colab**
  - Introdução ao ambiente de notebooks
  - Uso de células de código e texto
  - Execução em tempo real utilizando máquinas virtuais
- **Markdown**
  - Formatação de documentação de projetos
  - Uso de cabeçalhos, listas, links e estilos de texto (negrito e itálico)

### 2. Fundamentos da Linguagem

- **Funções Primárias**
  - Uso de funções nativas como `print()`, `input()` e `type()`
- **Variáveis e Tipagem**
  - Tipos primitivos: inteiros, floats, strings e booleanos
  - Regras de nomenclatura de variáveis
- **Manipulação de Strings**
  - Métodos como `.upper()`, `.lower()`, `.strip()` e `.replace()`
  - Formatação avançada utilizando *f-strings*

### 3. Lógica de Programação

- **Estruturas Condicionais**
  - Implementação de decisões com `if`, `elif` e `else`
  - Uso de operadores lógicos (`and`, `or`, `not`, `in`)
- **Estruturas de Repetição**
  - Laço `while` para repetições condicionais
  - Laço `for` para iteração sobre coleções de dados
  - Comandos de controle `break` e `continue`

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3  
- **Plataforma:** Google Colab (Jupyter Notebook)

## 📝 Exemplos de Aplicações Práticas

O notebook apresenta exercícios resolvidos que simulam situações do mundo real, tais como:

- Cálculo de IMC para monitoramento de saúde
- Classificação acadêmica com base em médias e critérios de aprovação
- Controle de acesso e estoque em sistemas de gestão
- Análise de dados de vendas e comparação de desempenho entre produtos
- Cálculo de orçamentos e projeções financeiras simples

## 🚀 Como Executar

1. Clone este repositório
2. Utilize o **Google Colab** ou certifique-se de ter o **Python** instalado localmente
3. Abra o arquivo `python_datascience.ipynb`
4. Execute as células para visualizar os resultados em tempo real
